# Es FTR - Aplikasi Usaha Es (PWA)

Cara pasang di GitHub Pages:
1. Buat repository baru di GitHub (mis. `es-ftr`), set Public.
2. Upload SEMUA isi folder ini (index.html, manifest.webmanifest, sw.js, folder icons).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. Tunggu 1-2 menit, buka https://USERNAME.github.io/es-ftr/
5. Di HP: menu browser > "Tambahkan ke layar utama" / "Install aplikasi".

Update aplikasi: ganti index.html, lalu naikkan versi CACHE di sw.js (es-ftr-v1 -> v2).
Data tersimpan di HP (localStorage), jadi rutin pakai fitur Backup di aplikasi.
